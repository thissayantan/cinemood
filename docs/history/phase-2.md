# Phase 2 — Add to watchlist

Built the TMDB ingestion path end-to-end. The Worker exposes `GET /api/search/tmdb?q=` (proxies TMDB `search/multi`, KV-cached for 1 day, filters out `person` hits, normalizes to `{id,type,title,release_date,poster_path,overview,vote_average}`) and `GET /api/title/:type/:id` (TMDB detail with `credits,keywords,watch/providers,external_ids` plus optional OMDB IMDb rating, both KV-cached, upserted into `titles`). Watchlist mutation lives at `POST /api/watchlist {tmdb_id,type}` (idempotent), `DELETE /api/watchlist/:id`, `PATCH /api/watchlist/:id {status}`, and `GET /api/watchlist[/ids]` for the saved-set hint. Frontend has a debounced search bar (350ms), a glassmorphism poster grid with framer-motion stagger, "Saved" badges from `/api/watchlist/ids`, ratings, and an optimistic add. Smoke test: typecheck + build green; with a manually-injected local session for `u_smoke`, `GET /api/me` returns the user, `GET /api/search/tmdb?q=blade runner` returns 17 hits, `POST /api/watchlist {tmdb_id:78,type:"movie"}` adds Blade Runner (1982), and `GET /api/watchlist` lists it back. Learned a Hono context-typing rule (committed to CLAUDE.md) after the first typecheck pass failed.
