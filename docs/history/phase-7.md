# Phase 7 — Polish + deploy

Polished the UI: a `light/dark/system` theme toggle backed by `apps/web/src/lib/theme.ts` and a tiny pre-React inline script in `index.html` that reads `localStorage.cm_theme` and sets `<html class="dark">` before paint to avoid flash; CSS variables (`--bg`, `--fg`, mesh alphas) drive the body and gradient mesh and flip between modes; the `dark` Tailwind variant was switched to a class-based `@custom-variant` so the few hardcoded color classes that still mattered (avatar pill, theme button) gained light counterparts. Added a real 404 page (`apps/web/src/pages/not-found.tsx`) with copy + link back home, wired into `<Route path="*">`. Bumped `index.html` with a fuller meta description, OG tags, twitter:card, and matching `theme-color` per scheme; favicon was already in place from Phase 0. Loading / empty / error states were already wired across home, watchlist, NL search, settings, and import — audited and confirmed nothing was missing.

Deploy: pushed all seven production secrets via `wrangler secret put --env production` (`TMDB_API_KEY`, `OMDB_API_KEY`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI` overridden to the prod callback, `SESSION_SIGNING_KEY`, `LLM_CONFIG_KEY`). `wrangler deploy --env production` shipped `cinemood-api` with the correct bindings (D1 `cinemood`, KV `SESSIONS`+`CACHE`, R2 `cinemood-index`, Workers AI) and attached both Worker routes to `cinemood.sayantan.cloud/api/*` and `/auth/*` (zone `sayantan.cloud`). Created the Pages project `cinemood` (`production-branch=main`), added an SPA `_redirects`, and deployed `apps/web/dist`; the default URL is live at <https://cinemood-789.pages.dev/> and serves the index plus correctly redirects unknown paths so client-side routing works. Attached the custom domain `cinemood.sayantan.cloud` via the Cloudflare Pages API (`success: true`, domain id captured).

Smoke tested what is reachable without DNS: typecheck + build green; the Pages deployment returns HTTP 200 with the right HTML on `/` and on a synthetic `/some/random/path`. The OAuth round-trip on the production hostname could not be exercised — the DNS CNAME for `cinemood.sayantan.cloud → cinemood.pages.dev` does not yet exist and the wrangler OAuth token in this session lacks the `dns_records:edit` scope, so the run paused per CLAUDE.md autonomous-mode condition #4 with a `BLOCKED.md` describing exactly what to add and how to verify.
