# Phase 4 — NL search

Built the full natural-language search pipeline. The Worker now has `apps/api/src/llm/` with a `LlmProvider` interface and concrete implementations for Cloudflare (`env.AI`), Anthropic, OpenAI, and Google Gemini, all behind a single `createLlmProvider(cfg, env)` factory. The query parser ships a single locked system prompt with synonym/decade/rating heuristics and a strict JSON shape that gets parsed via a brace-depth scanner (so multi-object or fenced LLM outputs no longer trip up `JSON.parse`) and validated against `ParsedQuerySchema` (`zod`) before anything reaches Orama. The Orama index lives in `apps/api/src/lib/orama-index.ts` with a `Map<userId, {db, docs}>` module-scope cache, R2 persistence at `index/{userId}.json`, lazy backfill from D1 on first request, and embeddings via `@cf/baai/bge-base-en-v1.5` (768-dim) over the title + overview + genres + keywords + top-cast text. Hybrid search routes through Orama with `mode:'hybrid'`, vector + term, plus a where-clause translator that handles the LLM filters (`type` enum, `genres`/`keywords`/`cast_names`/`providers` enum[], rating + year ranges via `{between}`, `exclude_genres` post-filter). `POST /api/search` returns `{parsed, results}` and the existing watchlist add/remove endpoints schedule index updates via `executionCtx.waitUntil`. Frontend has a dedicated NL search box above the watchlist with parsed-filter chips and a result card grid. Smoke test (against `wrangler dev --remote`, real Workers AI + D1 + KV + R2): 12 queries spanning bare-title, decade, rating, negation, cast, provider, type, vibe — all parse to valid JSON, route through Orama without errors, and return correct hits when present in the small 5-item watchlist (`Inception`, `Severance`, `Blade Runner`, `Blade Runner 2049`, `Breaking Bad`). Three real mistakes were corrected in-flight (gpt-oss response shape, Orama `properties` typing, Orama enum + range where syntax) and captured as Learned Rules in `CLAUDE.md`.
