# docs/history/

Archived development artifacts. **Not references for current state** — for present-day truth consult the top-level `docs/` files (especially `deploy.md` and `self-host-test.md`) or the code itself.

What's here, with rough date ranges:

- **`phase-0.md` – `phase-7.md`** — the autonomous-build log for the original Phase 0–7 plan (May 2026, the initial Cinemood build).
- **`design-audit.md`, `design-plan.md`, `design-research.md`** — the redesign pass that established the editorial-cinematic aesthetic direction. The plan is the "what we decided"; the audit is the "what was wrong before"; the research is the "what we looked at."
- **`audit-shots/`** — intermediate redesign screenshots from the same redesign pass. Ordered chronologically by filename prefix.
- **`production-finish.md`** — the original DNS / Cloudflare Pages migration story. The topology has since shifted to single-Worker (see top-level `deploy.md`); kept here as the record of how we got here.
- **`responsive-audit-2026-05.md`** — the mobile/iPad responsive fix analysis. The fix shipped; the analysis is preserved for the "why" trail.
- **`simplification-report-2026-05.md`** — the six Code Simplifier batches. The no-touch list and per-batch reasoning fed the Learned Rules in `CLAUDE.md`.

Each archived markdown file starts with an "Archived YYYY-MM-DD" blockquote naming what era it captures. If a future change makes one of these files actively load-bearing again, promote it back to top-level `docs/`.
