# Phase 1 — Auth

Implemented Google OAuth on the Worker (`/auth/google` and `/auth/google/callback`) with CSRF protected by a short-lived state cookie, plus session management backed by `SESSIONS` KV. Sessions are random 32-byte ids stored as `session:{id}` with 30-day TTL; the cookie is `HttpOnly`, `SameSite=Lax`, `Path=/`, and gets `Secure` in production. `authMiddleware` runs on every request, hydrates `c.var.user`, and `GET /api/me` returns the user or 401. The frontend has a logged-out landing page with a "Sign in with Google" button (and inline error rendering from `?auth_error=`), a logged-in home page with a glassmorphism greeting card and an avatar menu that calls `POST /auth/logout` and reloads. Smoke test: `bun run typecheck && bun run build` both pass; `wrangler dev --local` returns 401 from `/api/me` anonymously and a 302 from `/auth/google` to `accounts.google.com` with the right `client_id`, `redirect_uri`, scope `openid email profile`, and a CSRF state cookie.
