## Archived — `history/`

[`history/`](history/) holds development artifacts that captured a moment in time. They're kept for context (why certain decisions were made, what the product looked like during the autonomous build) but should NOT be read as current truth.

Inside `history/`:

- `phase-0.md` – `phase-7.md` — the autonomous-build log for the original Phase 0–7 plan.
- `design-audit.md`, `design-plan.md`, `design-research.md` — the critical audit + plan + research that drove the editorial-cinematic redesign.
- `production-finish.md` — the original production-deploy finish doc (the topology has since changed; see the project README's deploy section for current truth).
- `audit-shots/` — the 20+ intermediate redesign screenshots taken during the editorial-cinematic redesign.

Each archived markdown file starts with an "Archived YYYY-MM-DD" blockquote naming what era it captures.
