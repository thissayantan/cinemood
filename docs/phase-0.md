# Phase 0 — Bootstrap

Stood up the bun-workspaces monorepo (`apps/web`, `apps/api`, `packages/shared`) with the locked stack: React 18 + Vite + Tailwind v4 + Framer Motion + Google Sans on the web, Hono on the Worker, and `@cinemood/shared` for cross-workspace types. Wrangler bindings (D1 `cinemood`, KV `SESSIONS`/`CACHE`, R2 `cinemood-index`, Workers AI) were provisioned autonomously via `wrangler d1/kv/r2 create` and pinned into `apps/api/wrangler.toml` with a separate `[env.production]` block carrying the `cinemood.sayantan.cloud/api/*` and `/auth/*` routes. The schema in §5 of the spec was applied as `migrations/0001_init.sql` to both the local D1 simulator and the remote DB. Smoke test: `bun run typecheck` and `bun run build` both pass across all three workspaces, and `wrangler dev --local` answers `GET /api/health` with `{"ok":true,"data":{"status":"up",...}}`. MCPs `shadcn` and `21st-magic` were verified reachable before scaffolding.
