# Phase 3 — Watchlist view + filters

The home page now renders the user's watchlist as a glassmorphism poster grid below the search bar. `WatchlistGrid` queries `GET /api/watchlist?status=&type=&genre=&year=` (the API piece was already in Phase 2; this phase adds the UI), derives the available genre/year facets from the loaded items, and exposes them as a `FilterChips` row with status pills (All/To watch/Watched), a type selector (Any/Movies/Series), and toggleable genre + year chips. Cards are responsive (2/3/4/5-column at sm/md/lg breakpoints), use Framer Motion `layout` + `AnimatePresence` for stagger-on-mount and remove-on-exit, and reveal a slide-down action panel with "Watched/Unmark" (`PATCH`) and "Remove" (`DELETE`). Empty state and skeleton state are wired. Smoke test: typecheck + build green; over the local Worker with the seeded `u_smoke` session, adding Interstellar/Breaking Bad/Game of Thrones, filtering by `status=pending` (4) and `type=series` (2), `PATCH` Breaking Bad → watched (verified via `status=watched` returning 1), and `DELETE 1399` all succeed and the full list ends as Breaking Bad (watched), Interstellar (pending), Blade Runner (pending).
